## Changes

- **iOS build config is now CNG-complete** (`app.json`): `expo-apple-authentication` plugin + `ios.usesAppleSignIn` (the Sign in with Apple entitlement previously lived only in the gitignored `ios/` dir and would have been lost on any EAS/clean build), `ITSAppUsesNonExemptEncryption: false`, real purpose strings for the always-location and motion Info.plist keys, refreshed splash background and 1024px opaque iOS icon.
- **Sign in with Apple enabled** (`src/app/auth.tsx`): the `APPLE_SIGN_IN_ENABLED = false` gate is gone (paid Apple Developer Program in place, Team CJAFZA5NP9); the custom glyph button was replaced with Apple's official `AppleAuthenticationButton` per HIG.
- **In-app account deletion** (App Review Guideline 5.1.1(v)): new `delete-account` Supabase Edge Function (JWT-scoped self-deletion, cascade wipes profiles/favorites) + `deleteAccount()` in the auth context + destructive, double-confirmed "Delete account" action in the profile screen.
- **Apple token revocation on deletion** (TN3194): re-auth captures a fresh `authorizationCode`; the edge function exchanges it (ES256 client-secret JWT via jose), binds the returned identity to the caller before revoking, and treats revocation as best-effort with 10s deadlines so deletion always proceeds; the client surfaces manual-revocation instructions when revocation fails.
- **Session eviction hardening**: explicit `storageKey` (`nearly-departed-auth`) + guaranteed local session eviction after deletion even when the sign-out server call fails (one-time sign-out for pre-release beta sessions).
- **Truthful legal copy**: privacy policy and terms §6 now disclose that signed-in users' favorites and avatar choice sync to Supabase (guests stay device-only), and document in-app account deletion; `src/content/legal.ts` regenerated.
- **Tooling boundary**: `supabase/functions` excluded from the RN `tsc`/eslint surface with its own `deno.json`; edge-function test coverage recorded in `docs/4-unit-tests/COVERAGE-DEBT.md`.
- Silenced the known-noise `AuthRetryableFetchError` LogBox warning (`src/app/_layout.tsx`).
