## Changes

- New `.github/workflows/supabase-keepalive.yml`: GitHub Actions cron (`23 3,15 * * *` UTC, plus `workflow_dispatch`) issuing two RLS-safe PostgREST queries per run (`profiles?select=id&limit=1`, `favorites?select=user_id&limit=1`) with the publishable anon key, so the free-tier Supabase project keeps seeing database activity and is unlikely to hit its ~7-day inactivity pause (which already struck once, on 2026-08-17, and would break sign-in/sync — fatal during App Review). Non-200 or a hang fails fast (curl timeouts, `timeout-minutes: 2`) and triggers GitHub's failed-run email. Best-effort by design; Supabase Pro remains the only contractual fix.
- `.gitignore`: ignore `supabase/.temp/` (Supabase CLI local state).
- `app.json` `expo.version` intentionally stays 1.0.0 — the app binary is unchanged and the first App Store submission ships as 1.0.0; 1.0.1 is repo/infra versioning only (`package.json`).
- Post-merge verification still open (plan to-dos): green `workflow_dispatch` run, then a green first scheduled run.
