## Changes

- **Editable display name** (`docs/testflight-feedback.md` item 1): profile header shows a user-chosen name instead of the Apple private-relay email; tap-to-edit bottom sheet (keyboard-safe), avatar initial follows `displayName ?? email`. Synced to `profiles.display_name` mirroring the avatar pattern — AsyncStorage source of truth, best-effort Supabase mirror — with three hardening departures: user-scoped storage keys (guest vs per-account, so names never leak across accounts), a three-state value with a clear-tombstone (offline clears survive reconcile), and an intent counter so an in-flight reconcile can't clobber a fresh edit. Guest names promote to a first account only when the account has no name.
- **Friendly auth errors** (item 3): new `friendlyAuthMessage` helper with per-operation policy — send-code and Apple sign-in always show fixed copy (raw server messages, including JSON bodies, can never render); verify-code allowlists only known human token messages. Raw errors log under `__DEV__` only.
- **Privacy disclosures**: `legal/privacy-policy.md` + regenerated in-app copy now name the synced display name everywhere synced account data is described.
- **Migration**: `supabase/migrations/0003_display_name.sql` (additive column; RLS already covers it). Ops: run in dashboard SQL editor before shipping build 4.
- Tests: 16 new (sanitizer, merge matrix incl. tombstone/never-set regressions, message policies); suite 43 green.
- App Store marketing version stays 1.0.0; ships as iOS build 4 (EAS auto-increment). Remaining ops: hosted privacy page redeploy, ASC privacy label + Name, simulator verification, eas build/submit.
